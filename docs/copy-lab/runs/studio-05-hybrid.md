1. **Bridge hook:** "Catalogue-ready shoots, without the studio day." vs. a flat cost line ("On-model shots at a fraction of a studio shoot.") — does the time/logistics hook or the cost hook pull more scroll-depth?
2. **The owned trade-off (Step 04):** test the candid version ("if a print is off, we regenerate") against a confident-only version ("approved before it ships") to measure whether admitting the failure mode raises or lowers booking rate for this burned ICP.

4. **The cost number:** verify whether "80% cheaper" / "a fraction of a studio shoot" is defensible per-shot; A/B the specific "80%" against the softer "a fraction" — specific usually wins if it's true, but only ship the number we can stand behind.
