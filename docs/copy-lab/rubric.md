# Rubric — how the winner is chosen

Score each run on six dimensions, **1–5**. Max 30. The judge writes one sentence of evidence
per score (quote a line from the run). Ties break on **Voice fit**, then **Differentiation**.

A run that violates any **hard constraint** in `brief.md` §5 is capped at **2/5 on Brand-rule
compliance** and flagged — a disqualifier for shipping even if it scores well elsewhere.

---

### 1. Voice fit — *does it sound like NexAI?*
First principles, concrete, casual, no hedging, free value over pressure.
- **5** — reads like the sharpest version of the house voice; could ship as-is.
- **3** — competent but generic; could be any AI agency.
- **1** — wrong register (corporate, salesy, or precious).

### 2. Clarity — *does a stranger get "what NexAI does" in 5 seconds?*
Judge the hero + first scroll only for this score.
- **5** — the one-thing lands instantly, no jargon.
- **3** — gettable after a re-read.
- **1** — vague; could be selling software, consulting, or a SaaS tool.

### 3. Specificity — *concrete nouns and numbers, not adjectives?*
- **5** — names real things, uses real numbers, zero filler.
- **3** — some specifics, some hand-waving.
- **1** — adjective soup.

### 4. Persuasion without pushiness — *does it earn the click by teaching?*
- **5** — gives real value up front; CTA feels like an open door.
- **3** — standard CTA, neither pushy nor generous.
- **1** — pressure tactics, fake urgency, or beggy CTAs.

### 5. Brand-rule compliance — *constraints in brief.md §5 honored?*
- **5** — zero time commitments, zero banned adjectives, one canonical roster, no false claims.
- **3** — one minor slip.
- **2 or below** — any hard-constraint violation (auto-flag).

### 6. Differentiation — *memorable vs. the generic AI-agency template?*
- **5** — a line you'd remember and repeat; clearly not template copy.
- **3** — solid but forgettable.
- **1** — indistinguishable from a thousand landing pages.
